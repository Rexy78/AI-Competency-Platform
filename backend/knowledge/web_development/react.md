# React

React is a declarative, efficient, component-based JavaScript library for building user interfaces.

## Essential Concepts
- Functional Components and JSX
- Hooks: `useState`, `useEffect`, `useContext`, `useMemo`, `useCallback`, `useRef`
- Custom Hooks for reusable logic (e.g. data fetching, auth state)
- State Management: Context API, Zustand, Redux Toolkit
- Routing: React Router v6
- Styling: Tailwind CSS, CSS Modules, Styled Components

## Best Practices
- Keep components modular, focused, and pure
- Manage side effects cleanly with cleanup functions in `useEffect`
- Optimize re-renders with `React.memo` and memoized callbacks
