# Node.js & Express

Node.js is an open-source, cross-platform JavaScript runtime environment executing code outside the browser using Google's V8 engine.

## Key Features
- Single-threaded event loop with non-blocking I/O model
- Express.js middleware pattern for request/response pipelines
- NPM package ecosystem
- Real-time communication with WebSockets / Socket.io
- Database connection pools (Mongoose for MongoDB, Knex/Prisma/TypeORM for SQL)
