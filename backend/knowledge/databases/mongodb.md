# MongoDB & NoSQL

MongoDB is a source-available, cross-platform document-oriented database classified as NoSQL.

## Core Characteristics
- Stores data in flexible, JSON-like BSON documents
- Dynamic schemas allowing records without fixed column definitions
- Rich query language supporting secondary indexes, aggregation pipelines, and text search
- Horizontal scalability via sharding and high availability via replica sets
- Used in MEAN/MERN stacks, high-volume logging, and rapid prototyping
