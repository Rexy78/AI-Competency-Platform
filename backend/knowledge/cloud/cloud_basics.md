# Cloud Computing Fundamentals

Cloud computing delivers on-demand computing services—including servers, storage, databases, networking, software, and analytics—over the Internet.

## Core Models
- IaaS (Infrastructure as a Service): AWS EC2, Google Compute Engine, Azure VMs
- PaaS (Platform as a Service): Heroku, AWS Elastic Beanstalk, Render
- SaaS (Software as a Service): Google Workspace, GitHub, Slack
- Serverless: AWS Lambda, Cloud Functions, Vercel

## Key Cloud Architecture Principles
- High Availability (HA) across multiple Availability Zones (AZs)
- Horizontal Auto-scaling with Load Balancers (ALB / NLB)
- Infrastructure as Code (IaC) with Terraform and CloudFormation
