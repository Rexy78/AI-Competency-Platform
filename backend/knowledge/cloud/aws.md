# Amazon Web Services (AWS)

AWS is the world's most comprehensive and broadly adopted cloud platform.

## Key Services for Backend Developers
- Compute: EC2 (virtual servers), AWS Lambda (serverless compute), ECS / EKS (container orchestration)
- Storage: S3 (Simple Storage Service for object/file storage)
- Databases: RDS (managed MySQL/PostgreSQL), DynamoDB (managed NoSQL)
- Networking & Security: VPC, IAM (Identity and Access Management), Security Groups, API Gateway
- Messaging: SQS (queueing), SNS (pub/sub notifications)
