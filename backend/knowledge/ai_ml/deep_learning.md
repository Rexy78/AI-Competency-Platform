# Deep Learning & Neural Networks

Deep Learning uses artificial neural networks with multiple layers (deep architectures) to model complex non-linear representations.

## Key Architectures
- Artificial Neural Networks (ANN / MLP): Dense layers, activations (ReLU, Sigmoid, Softmax)
- Convolutional Neural Networks (CNN): Image classification, object detection (ResNet, YOLO)
- Recurrent Neural Networks (RNN / LSTM / GRU): Sequential time-series data
- Transformers: Self-attention mechanism, multi-head attention, positional encodings

## Frameworks
- PyTorch: Dynamic computational graph, industry standard for AI research and production
- TensorFlow / Keras: Production deployment and edge devices (TF Lite)
