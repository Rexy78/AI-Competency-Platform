# Natural Language Processing (NLP) & Large Language Models (LLMs)

NLP and GenAI represent modern intelligence systems processing and generating human language.

## Key Concepts
- Tokenization (Byte-Pair Encoding, WordPiece), embeddings (vector representations in high-dimensional space)
- Cosine similarity, vector databases (ChromaDB, FAISS, Pinecone)
- Transformer architecture: Encoder-Decoder (T5), Autoregressive Decoders (GPT, Gemini, LLaMA)
- Prompt Engineering: Few-shot prompting, chain-of-thought reasoning, system instructions
- Retrieval-Augmented Generation (RAG): Grounding LLMs on domain knowledge bases to eliminate hallucinations
