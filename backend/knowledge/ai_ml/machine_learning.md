# Machine Learning & AI Fundamentals

Machine Learning enables systems to learn and improve from data without being explicitly programmed.

## Types of Machine Learning
- Supervised Learning: Linear Regression, Logistic Regression, Decision Trees, Random Forests, XGBoost
- Unsupervised Learning: K-Means Clustering, PCA (Principal Component Analysis), DBSCAN
- Reinforcement Learning: Q-learning, Policy Gradients, RLHF (Reinforcement Learning from Human Feedback)

## Core Pipeline & Tools
- Data prep: Pandas, NumPy, Feature Engineering, Imputation, Standard Scaling
- Modeling & Evaluation: Scikit-Learn (accuracy, precision, recall, F1-score, ROC-AUC)
- Cross-validation: K-Fold, stratified splits, hyperparameter tuning (GridSearchCV, Optuna)
