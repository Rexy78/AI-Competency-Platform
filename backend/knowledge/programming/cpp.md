# C++

C++ is a high-performance, compiled, general-purpose language with object-oriented and generic programming capabilities.

## Key Focus Areas
- Memory management, pointers, references, RAII (Resource Acquisition Is Initialization), smart pointers
- Standard Template Library (STL): vectors, maps, sets, queues, algorithms
- Object-Oriented design: polymorphism, virtual functions, abstract base classes
- Systems programming, competitive programming, low-latency applications, and game development
