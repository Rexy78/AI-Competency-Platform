# JavaScript & TypeScript

JavaScript is the core language of the modern web, running in browsers and Node.js servers. TypeScript adds static typing, interfaces, and compile-time type safety.

## Core Concepts
- ES6+ features: arrow functions, destructuring, modules, template literals, optional chaining
- Asynchronous patterns: Promises, async/await, event loop, microtask queue
- DOM manipulation, event listeners, and browser APIs
- TypeScript: interfaces, generic types, union types, type guards, strict null checks

## Frameworks & Tooling
- Frontend: React, Next.js, Vue, Angular
- Backend: Node.js, Express, NestJS
- Tooling: Vite, Webpack, ESLint, npm, yarn, pnpm

## Learning Roadmap
1. Modern JavaScript (ES6+), closures, prototypes
2. Asynchronous JavaScript & Fetch/Axios API
3. TypeScript fundamentals and type declarations
4. Component-driven frontend architecture with React
