# Python

Python is an interpreted, high-level, dynamically-typed programming language renowned for simplicity, readability, and versatile ecosystem.

## Core Concepts
- Syntax, data structures (lists, tuples, dictionaries, sets), comprehensions, generators, and decorators
- Object-Oriented Programming (OOP): classes, inheritance, dunder methods, encapsulation
- Asynchronous programming with `asyncio`, coroutines, and event loops

## Key Ecosystem & Frameworks
- Backend: FastAPI, Django, Flask, SQLAlchemy, Pydantic
- Data Science & AI: NumPy, Pandas, Scikit-learn, PyTorch, TensorFlow, spaCy
- Tooling: Poetry, pip, pytest, Black, Ruff

## Learning Path & Prerequisites
1. Core Python and standard library
2. Web APIs with FastAPI or Django REST Framework
3. Database ORM integration (SQLAlchemy / PostgreSQL)
4. Containerization with Docker and deployment
